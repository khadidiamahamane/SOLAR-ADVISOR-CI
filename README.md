# ☀️ SolarAdvisor

**SolarAdvisor** est une application mobile Android dédiée à la transition énergétique. Elle a pour objectif de faciliter la mise en relation entre les PME ayant des besoins en solutions énergétiques et les professionnels spécialisés dans les équipements solaires.

## Présentation du projet

SolarAdvisor propose une approche simplifiée pour accompagner les entreprises dans leur transition vers des solutions énergétiques plus durables.

L'application permet notamment d'envisager une première estimation des besoins énergétiques d'une entreprise à partir de ses équipements électriques et de sa consommation. Cette estimation peut aider à identifier les solutions adaptées, notamment en matière de panneaux solaires, d'onduleurs et de groupes solaires.

La plateforme a également pour vocation de mettre en relation les entreprises avec des professionnels et partenaires du secteur énergétique, qui peuvent présenter leurs services, leurs produits et leurs domaines d'expertise.

## Objectifs

- Faciliter l'accès aux solutions d'énergie solaire.
- Proposer une première estimation des besoins en équipements.
- Mettre en relation les PME avec des professionnels de la transition énergétique.
- Améliorer la visibilité des fournisseurs et prestataires spécialisés.
- Encourager l'adoption de solutions énergétiques durables.

## Technologies utilisées

| Technologie | Utilisation |
|---|---|
| Kotlin | Langage de programmation |
| Android Studio | Environnement de développement |
| Firebase Authentication | Authentification des utilisateurs |
| Cloud Firestore | Service Firebase exploré dans le cadre du projet |

## Plateforme

SolarAdvisor est développée pour **Android** avec Kotlin.

L'application n'est pas encore publiée sur le Google Play Store.

## Installation et exécution

1. Cloner le dépôt :

   ```bash
   git clone https://github.com/TON-PSEUDO/SolarAdvisor.git
   ```

2. Ouvrir le projet dans Android Studio.

3. Configurer Firebase en ajoutant le fichier `google-services.json` correspondant à votre projet Firebase dans le dossier `app/`, si nécessaire.

4. Synchroniser le projet avec Gradle.

5. Exécuter l'application sur un émulateur Android ou un appareil compatible.
